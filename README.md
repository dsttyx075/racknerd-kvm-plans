## 什么是 Linux VPS，谁真正需要它

Linux VPS 是在运行 Linux 发行版的虚拟化服务器上租用的专用资源——保证 CPU 核心、RAM 和磁盘空间——并附带完整的 root 权限。一项行业对比估计，大约 70% 的 VPS 实例运行某种版本的 Linux，原因不难理解：操作系统免费，运行效率比 Windows 更高，而且你可以控制整个技术栈。

与共享主机（shared hosting）的区别在于资源和控制权。在共享主机上，数百个账户共用一台机器，服务商决定你可以安装什么，你的网站性能受到“嘈杂的邻居”的影响。而在 VPS 上，你获得已公布且预留的资源、root 权限，以及随之而来的一切：任何软件、你自己的防火墙规则、cron 任务、VPN、你想要运行的任何服务。

谁不需要 VPS？如果 SSH 听起来像作业，而你的网站只是一个包含联系表单的展示页面，那么托管型共享主机在你花的时间成本上可能更划算。当你需要控制权，或者需要运行特定需求（私人 VPN、机器人、开发环境、需要 root 权限的网站）时，VPS 就能体现其价值。

## 1 GB（或 2.5 GB）VPS 实际能运行什么

对于微型工作负载，它能运行的比你想象的要多；但对于任何数据库密集型的任务，它能运行的比你期望的要少。

在 1 GB 上表现良好：

- 配置了 nginx 和缓存的静态网站或小型博客

## 托管与非托管：优先决定这一点

RackNerd 的廉价套餐是非托管的，这正是它能定这个价格的原因。非托管意味着你需要通过 SSH 登录、运行系统更新、配置防火墙、整理 SSL 证书，并自己设置备份。如果这对您来说是一个普通的日常操作，那么使用非托管计划可以节省大量资金。如果这听起来像是不想度过的周末，那么托管 Linux VPS 才是正确的方案——根据上述列表，其入门价格在每月 7 到 8 美元左右，大约是 RackNerd 实际月费成本的七倍。这两种情况都合理；只是要确保你选择的模式是你真正能够忍受的。

一个折中方案：利用自动化安装脚本或控制面板，在非托管服务器上运行一个像 WordPress 这样标准的工具栈。你既保留了廉价的价格，又减少了终端操作的时间。

## 选择哪个 Linux 发行版

不确定的话，就选 Ubuntu LTS——它拥有所有服务器操作系统中最大的教程生态系统，所以几乎每一个指南都能直接照搬使用。除此之外的选择则取决于具体需求：

- **Debian** 追求极致稳定性，这也是为什么它是 Ubuntu 的基础，以及为什么长期运行的生产服务器通常选择它
- **AlmaLinux** 或 **Rocky Linux**，当软件需要 RHEL 兼容性时——cPanel 是经典案例，因为它对 RHEL 系列有绑定要求
- **Alpine** 用于容器，其约 5 MB 的基础镜像让 RAM 留给实际的应用程序使用

在 KVM 服务器上，以上所有发行版（以及其他更多版本）都可以通过 RackNerd 的镜像模板安装，并且自定义 ISO 涵盖了其他一切需求。
